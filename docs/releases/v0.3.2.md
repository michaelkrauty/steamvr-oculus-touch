# cv1touch v0.3.2

This patch fixes controllers remaining fixed in mid-air while rotation continues after a sleep or clock discontinuity. It changes the shared Linux/Windows tracking code, without changing sensor calibration, headset registration or SteamVR room setup.

## What changed

- **Recover position tracking after a clock discontinuity.** Pending camera frames could retain timestamps from the old clock mapping and repeatedly displace every new observation. The tracker now discards that obsolete work when timing continuity is lost, allowing fresh optical frames to be processed.
- **Require a fresh optical fix after waking.** A pre-sleep position is no longer re-stamped as current when the controller's clock reports only a tiny elapsed interval across a longer sleep. Normal short buffered radio bursts retain their tracking history, and recovery of one controller does not reset the other.

Regression tests reproduce both failures on the old code and verify recovery with the fix. Live position tracking has also been verified on Linux. Automated Linux and Windows checks cover Rust 1.85 and stable, native tests, the driver/daemon contract and installer behavior. **Physical Windows USB streaming, calibration and gameplay remain unvalidated.**

## Install or upgrade

**Linux x86-64:** `steamvr-oculus-touch-0.3.2.tar.gz` contains the complete source and vendored dependencies. Build against your distribution's native libraries using the [setup guide](https://github.com/michaelkrauty/steamvr-oculus-touch/blob/v0.3.2/docs/setup.md). Follow the [upgrade instructions](https://github.com/michaelkrauty/steamvr-oculus-touch/blob/v0.3.2/docs/setup.md#upgrade), including restarting the daemon to load the fix.

**Windows 11 x64:** download `cv1touch-setup-0.3.2.exe`, quit SteamVR, and follow the [Windows guide](https://github.com/michaelkrauty/steamvr-oculus-touch/blob/v0.3.2/docs/windows.md). The installer is unsigned. Do not disable Windows security or download DLLs from third-party sites if it is blocked; report the exact message instead. Hardware testers should use the [first Windows test checklist](https://github.com/michaelkrauty/steamvr-oculus-touch/blob/v0.3.2/docs/windows-first-test.md).

Settings and calibration are retained; no recalibration or Room Setup is required for this patch. Shared-memory ABI **v4** is unchanged from v0.3.0 and v0.3.1, so this fix does not require a new SteamVR driver ABI. When upgrading from v0.2.0, update the daemon and SteamVR driver together.
