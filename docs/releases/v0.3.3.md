# cv1touch v0.3.3

This patch improves tracking recovery, recording isolation, driver shutdown, and installation reliability. It also reduces optical-fit work and bounds support-report memory. Settings, sensor calibration, headset registration, and SteamVR room setup are retained.

## What changed

- **Safer tracking recovery.** Recoverable camera USB completion errors no longer permanently remove capture slots. Controller timestamp conversion preserves long report gaps, and native tracking starts a fresh continuity epoch after an IMU sample gap over 100 ms instead of propagating through missing measurements. Stale optical priors are retired; the held pose and calibration remain intact until fresh observations arrive.
- **Recording and shutdown fixes.** Late producers cannot write into a different recording session or inherit its frame setting. SteamVR device deactivation waits for admitted pose/input submissions to finish before returning.
- **Less optical-fit work.** Final residual checks no longer calculate Jacobians they do not use. A synthetic 12-pair fit uses 984 rather than 1,128 projections, with approximately 3–6% lower whole-fit CPU time in repeated measurements. This is not a measured end-to-end tracking-latency improvement.
- **Bounded diagnostic and settings input.** Support reports retain the same journal tail without keeping the whole stream in memory; they still read the entire stream. Settings must be a regular file no larger than 1 MiB. Registration loading rejects invalid station rotations while retaining finite scaled quaternions.
- **More reliable installation cleanup.** Installer journals are published atomically before payload replacement. Uninstall refuses skip options that would leave owned service or driver integrations behind without their payload and cleanup metadata.

Hardware-independent regressions cover the failures, native covariance recovery and stale-camera callbacks, recording races, driver deactivation, and installer faults. Automated Linux and Windows checks cover Rust 1.85 and stable, the native engine, driver/daemon contract, and installer behavior. **Physical Windows USB streaming, calibration, and gameplay remain unvalidated.**

## Install or upgrade

**Linux x86-64:** `steamvr-oculus-touch-0.3.3.tar.gz` contains the complete source and vendored dependencies. Build against your distribution's native libraries using the [setup guide](https://github.com/michaelkrauty/steamvr-oculus-touch/blob/v0.3.3/docs/setup.md). Follow the [upgrade instructions](https://github.com/michaelkrauty/steamvr-oculus-touch/blob/v0.3.3/docs/setup.md#upgrade).

**Windows 11 x64:** download `cv1touch-setup-0.3.3.exe`, quit SteamVR, and follow the [Windows guide](https://github.com/michaelkrauty/steamvr-oculus-touch/blob/v0.3.3/docs/windows.md). The installer is unsigned. Do not disable Windows security or download DLLs from third-party sites if it is blocked; report the exact message instead. Hardware testers should use the [first Windows test checklist](https://github.com/michaelkrauty/steamvr-oculus-touch/blob/v0.3.3/docs/windows-first-test.md).

Quit SteamVR before upgrading, install both the daemon and SteamVR driver, and restart the daemon afterward. Shared-memory ABI **v4** is unchanged, but both components have fixes in this release. No recalibration or Room Setup is required.

`SHA256SUMS` covers the source archive and Windows installer.
