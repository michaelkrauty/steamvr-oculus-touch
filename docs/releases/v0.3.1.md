# cv1touch v0.3.1

This patch release fixes Windows first-run blockers and makes installation, repair and support reporting more reliable. It prepares the project for a controlled first Windows hardware test; **physical Windows USB streaming, calibration and gameplay are still unvalidated**.

## What changed

- **No extra Visual C++ runtime required.** The Windows executables now include their C runtime. The v0.3.0 installer could fail to start on a PC without an independently installed Visual C++ Redistributable. CI now checks every bundled executable and DLL for unshipped dependencies.
- **Recognize the CV1 sensor's grouped USB function.** Windows can expose the camera's control/video interfaces as one device node. Discovery no longer waits indefinitely for a second node that will never appear; healthy WinUSB binding and active interfaces are still required.
- **Safer installation and recovery.** Quit SteamVR before installing, repairing or removing cv1touch. Repair stops acquisition before changing sensor drivers, restarts afterward and reports partial failures. Canceling uninstall leaves tracking running. Incomplete installation no longer immediately offers calibration.
- **Reliable background launch and useful reports.** The supervisor no longer inherits parent handles that can hold a captured setup command open. Installer, uninstaller and repair logs are retained and included in **Send a cv1touch report**.

Automated Windows checks exercise the real installer as a fresh non-administrator, including Unicode/space/ampersand installation paths, shortcuts, repair, upgrade, canceled uninstall, active-SteamVR refusal, diagnostics and cleanup while preserving settings. Separate tests bind the inbox WinUSB driver to a disposable synthetic device and load the packaged SteamVR driver DLL. These tests do not substitute for physical USB transfers, UAC interaction or the real SteamVR runtime.

## Install or upgrade

**Windows 11 x64:** download `cv1touch-setup-0.3.1.exe`, quit SteamVR, and follow the [Windows guide](https://github.com/michaelkrauty/steamvr-oculus-touch/blob/v0.3.1/docs/windows.md). The installer is unsigned. Do not disable Windows security or download DLLs from third-party sites if it is blocked; report the exact message instead.

You need a headset already working in SteamVR, a USB-connected CV1 headset as the radio receiver, already-paired CV1 Touch controllers and fixed CV1 sensors. Controller pairing, Rift S/Quest controllers and the CV1 display are not supported. Invited testers should use the [first Windows hardware test checklist](https://github.com/michaelkrauty/steamvr-oculus-touch/blob/v0.3.1/docs/windows-first-test.md).

If setup is incomplete, use **Finish setting up cv1touch** after resolving the stated prerequisite. For help, use **Send a cv1touch report** and share its ZIP privately: it contains settings, room calibration, device identities and logs, and does not upload itself. Keep sensors connected when uninstalling so their driver bindings can be removed.

**Linux x86-64:** `steamvr-oculus-touch-0.3.1.tar.gz` contains the complete source and vendored dependencies. Build locally using [the setup guide](https://github.com/michaelkrauty/steamvr-oculus-touch/blob/v0.3.1/docs/setup.md). There are no Linux tracking-algorithm or calibration-format changes in this patch; an already-working v0.3.0 installation does not need an urgent upgrade for these Windows fixes.

Settings and calibration are retained. Shared-memory ABI **v4** is unchanged from v0.3.0. When upgrading from v0.2.0, update the daemon and SteamVR driver together; see the [upgrade notes](https://github.com/michaelkrauty/steamvr-oculus-touch/blob/v0.3.1/docs/setup.md#upgrade).

`SHA256SUMS` covers the source archive and Windows installer.
